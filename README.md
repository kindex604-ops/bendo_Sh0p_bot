# BendoShop — магазин аккаунтов (aiogram 3 + SQLite)

## Запуск в Windows / VS Code

1. Установите Python 3.10+.
2. Откройте эту папку в VS Code.
3. В терминале выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

4. Откройте `.env` и укажите:
   - `BOT_TOKEN` — токен от @BotFather;
   - `ADMIN_ID` — ваш Telegram ID;
   - `CHANNEL_USERNAME` — канал магазина, например `@bendoShop`.
5. Добавьте бота администратором канала, чтобы проверка подписки работала.
6. Запустите: `python bot.py`.

## Команды администратора

- `/admin` — помощь.
- `/addaccount USA | 2012 | Нет | Привязана | Активен | 399 | Описание | Данные_выдачи` — добавить товар.
- `/stock` — склад.
- `/orders` — ожидающие заказы.
- `/deliver ID_заказа AUTO` — выдать сохранённые при добавлении данные.
- `/deliver ID_заказа текст` — выдать текст вручную.
- `/gift ID_покупателя | USA` — подарить первый доступный аккаунт страны; он появится в инвентаре покупателя.
- `/inventory` — покупатель смотрит свой инвентарь.
- `/resell ID_инвентаря цена` — только администратор выставляет подаренный аккаунт повторно.
- `/addbalance ID сумма` — пополнить баланс пользователя.
- `/notice текст` — сохранить объявление.

## Комиссия при перепродаже

При продаже повторно выставленного подаренного аккаунта магазин удерживает 30%, а владельцу инвентаря начисляется 70%. Продажа и выставление доступны только администратору. Пользователи не могут создавать объявления самостоятельно.

## Покупка и выдача

1. Пользователь подписывается на канал и принимает соглашение.
2. Открывает каталог и выбирает товар.
3. Покупка списывает средства с внутреннего баланса и создаёт заказ.
4. Покупателю приходит сообщение об ожидании выдачи до 60 минут.
5. Администратор выполняет `/deliver ID AUTO`; бот отправляет товар и инструкцию сменить пароль, проверить/привязать личную почту и настройки безопасности.

## Важно

- Бот не обрабатывает и не пересылает SMS/OTP-коды.
- Добавляйте только аккаунты, которыми вы законно вправе распоряжаться.
- Данные выдачи хранятся в SQLite в открытом виде. Не публикуйте файл базы, ограничьте доступ к серверу и делайте резервные копии.
- `.env` содержит токен бота — никому его не отправляйте.
- Перед использованием проверьте правила сервиса, аккаунты которого продаются.
